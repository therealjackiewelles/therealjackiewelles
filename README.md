## Hi, I'm Morgan 👋

I'm a freelance PA Technician with SSE Audio. I fly PA systems and look after audio networking for large-scale touring productions. I'm currently on Harry Styles' *Together, Together* World Tour.

My day-to-day work covers PA deployment, system configuration and the networked audio infrastructure behind arena and stadium shows. That includes AVB/Milan networks, gPTP clocking, L-Acoustics system configuration and managed switching. Alongside touring, I build software that gives engineers better visibility of the systems they're responsible for.
